Build and run

On a Linux x86_64 host with GCC, GNU binutils, GNU Make, Python 3, QEMU, OVMF and xorriso installed:

make
make run       # UEFI QEMU, serial console
make run-gui   # UEFI QEMU, graphical display

The normal boot profile expects a supported AHCI controller and a disk with SilliconFS as its root filesystem. Hardware support is evolving.
